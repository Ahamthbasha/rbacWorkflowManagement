# RBAC Backend (TypeScript + Node + Express + MySQL)

Quick start:

1. Create a `.env` file at the project root with DB variables:

```
DB_HOST=localhost
DB_USER=root
DB_PASS=
DB_NAME=rbac_db
PORT=3000
```

2. Install dependencies:

```bash
npm install
```

3. Run in development:

```bash
npm run dev
```

4. Build and run:

```bash
npm run build
npm start
```

This scaffold provides an MVC layout in `src/` with example controller, route, and DB pool.
